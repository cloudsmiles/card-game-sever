## 测试工具

### Chrome DevTools
1. **Elements**: 检查 DOM 结构和样式
2. **Console**: 查看日志和错误
3. **Network**: 查看 WebSocket 连接和 API 请求
4. **Performance**: 检查性能和动画帧率
5. **Lighthouse**: 运行性能和可访问性审计

### 快捷键
- `Cmd + Option + I`: 打开 DevTools
- `Cmd + Shift + M`: 切换设备模拟器
- `Cmd + R`: 刷新页面
- `Cmd + Shift + R`: 强制刷新（清除缓存）

## 常见问题排查

### 问题 1: 页面空白
- 检查控制台是否有错误
- 检查开发服务器是否运行
- 检查网络连接

### 问题 2: WebSocket 连接失败
- 检查后端服务器是否启动
- 检查 WebSocket URL 配置
- 查看 Network → WS 标签

### 问题 3: 样式异常
- 检查主题是否正确加载
- 检查 CSS 是否有冲突
- 尝试切换主题

### 问题 4: 动画卡顿
- 打开 Performance 标签录制
- 检查是否有大量重绘
- 检查是否有内存泄漏
